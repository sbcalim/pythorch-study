# pythorch-study

This is only a study repository used to learn PyTorch. It contains small exercises and notes as I work through PyTorch basics — there is no production code and no guarantees of correctness or stability here.

## Contents

- `Overview/` — introductory PyTorch exercises
- `Tensors/` — exercises focused on tensor basics

## Notes

- Each subfolder is a separate PyCharm project with its own virtual environment (`.venv/`), which is intentionally excluded from version control (see `.gitignore`).
- Downloaded datasets (e.g. FashionMNIST) are also excluded and can be re-downloaded by running the scripts.
